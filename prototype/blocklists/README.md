One file per category: adult.txt, gambling.txt, drugs.txt (add violence.txt etc. in later phases; the file name is the category).
Accepted line formats (blank lines and # comments ignored):
  example.com
  *.example.com
  0.0.0.0 example.com        (hosts-file format)
Subdomains are matched automatically (listing bad.test also blocks www.bad.test, but not notbad.test).

The .txt files here contain PLACEHOLDER domains (reserved .test names) so the engine can be demonstrated.
They do NOT block any real site. Before real use, replace them with a maintained list from a source you have
vetted and whose licence allows your use (PRD open question 6).
